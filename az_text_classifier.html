🗣️ Azerbaijani Sentiment Analysis

YouTube Dataset + FastText + GRU

An NLP pipeline for Azerbaijani-language sentiment classification using FastText embeddings and GRU neural networks. Collected 36K YouTube comments across 5 domains, achieving Macro-F1 of 0.8016 with frozen embeddings.

Course: CENG442 Natural Language Processing · Author: Abdullah Yusuf Erdem · March 2026

← Back to Portfolio View on GitHub

📋 Project Overview

This project builds a sentiment classification system for Azerbaijani text using FastText embeddings and GRU neural networks. It combines a labeled dataset (55,673 samples) with 2,910 YouTube videos scraped across 5 semantic domains, achieving a Macro-F1 score of 0.8016 on held-out test data.

🏆 Key Achievement

FastText frozen embeddings outperformed all other configurations, demonstrating the importance of preserving pre-trained linguistic knowledge for morphologically rich languages like Azerbaijani.

🎯 Project Objectives

  • Extend Part 1 labeled sentiment dataset with YouTube domain-specific data
  • Map sources to 5 semantic domains (Finance, Technology, Retail, Public Services, Social Life)
  • Implement robust Azerbaijani language filtering to remove Turkish/English noise
  • Build embedding matrices using Word2Vec and FastText
  • Train and evaluate GRU-based sentiment classifier
  • Compare frozen vs. fine-tuned embeddings
  • Perform error analysis and provide actionable insights

🛡️ Azerbaijani Language Filtering

Implemented a Two-Layer Intelligent Filter to remove Turkish and English noise from YouTube comments:

Layer A: Character-Based Detection

Schwa (ə): +4.0 points (unique to Azerbaijani)
Frequent 'q' and 'x': +1.5 points if count ≥ 2 (rare in Turkish)

Layer B: Lexicon-Based Scoring

Azerbaijani markers: +1.5 pts each (mən, sən, biz, deyil, hansı, üçün…)
Turkish markers: −5.0 pts each (değil, için, bence, kanka, güzel…)
Decision threshold: Score ≥ 2.5

252,872 Raw Comments
36,181 Filtered (Azerbaijani)
85.7% Noise Removal Rate

🧠 Embedding Matrix Construction

Combined Corpus: 124,353 sentences (Part 1) + 34,775 sentences (YouTube) = 159,128 total sentences

FastText Model Configuration

  • Vector size: 300 dimensions
  • Window: 5 (context window)
  • Min count: 3
  • Architecture: Skip-gram (sg=1)
  • Vocabulary: 90,168 words
  • Keras tokenizer vocabulary: 108,124 tokens
  • OOV rate: 0% (FastText subword advantage)

Key Feature: FastText's subword-based approach means even out-of-vocabulary words receive meaningful representations from their character n-grams—critical for Azerbaijani's agglutinative morphology.

🔬 Frozen vs. Fine-Tuned Embeddings

✅ Frozen Embeddings (Winner)

  • F1 Score: 0.8016
  • Better generalization
  • Preserves linguistic knowledge
  • Stable training curve
  • Appropriate for small labeled datasets

❌ Fine-Tuned Embeddings (Overfitting)

  • F1 Score: 0.7508
  • Catastrophic forgetting
  • 98% train accuracy, 75% validation
  • Val loss explosion: 0.42 → 1.02
  • Poor generalization to YouTube

Root Cause: Catastrophic Forgetting

The 300-dimensional embedding space has 32.4M parameters (108,124 words × 300 dims) but only 55,673 training samples — a ratio of ~581 parameters per example. Fine-tuning forced embeddings to overspecialize, forgetting general linguistic knowledge learned from the 159K-sentence corpus.

🏗️ GRU Neural Network Architecture

Input: Tokenized sequences (max_len=100)
         ↓
Embedding Layer
  - vocab_size: 108,124
  - embedding_dim: 300
  - trainable: False (FROZEN)
  - mask_zero: True
         ↓
SpatialDropout1D (rate=0.2)
         ↓
GRU Layer
  - units: 64
  - return_sequences: False
         ↓
Dropout (rate=0.3)
         ↓
Dense Layer
  - units: 2
  - activation: softmax
         ↓
Output: [P(Negative), P(Positive)]

Training Configuration

  • Optimizer: Adam (lr=0.001)
  • Loss: Sparse categorical cross-entropy
  • Batch size: 256
  • Epochs: 10 (early stopping ~epoch 7-8)
  • Train/Val split: 90/10 (stratified)
  • Hardware: Apple Silicon M-series (CPU)

🔤 Word2Vec vs. FastText: Why FastText Wins

Azerbaijani is a highly agglutinative language with multiple stacked suffixes. This creates enormous challenges for word-level embedding models:

Base word: telefon (phone)

Inflected forms:
  telefonlar        (phones)       → OOV in Word2Vec
  telefonlarım      (my phones)    → OOV in Word2Vec
  telefonlarımız    (our phones)   → OOV in Word2Vec
  telefonlarımızdan (from our phones) → OOV in Word2Vec

FastText: ALL forms get meaningful vectors via subword n-grams
Word2Vec OOV rate: 26.58% (28,627 / 108,124 tokens → zero vectors)

1. Subword Information

FastText decomposes words into character n-grams, capturing morphological structure and preserving semantic similarity across inflections.

2. Zero OOV Rate

Can generate vectors for any word using subword info. Word2Vec lost 26.58% of tokens to zero vectors — massive information loss.

3. YouTube Robustness

Handles misspellings, informal language, abbreviations, and code-switched Azerbaijani-Turkish comments naturally.

⚠️ Error Analysis

Error 1: Catastrophic Forgetting (Fine-Tuned)

Training accuracy reached 98%+ while validation accuracy stalled at 75-76%. The 32.4M embedding parameters vs. 55K training samples created a ~581:1 parameter-to-sample ratio, causing extreme overfitting.

Error 2: Word2Vec OOV Issues

26.58% of tokens replaced with zero vectors. Comments with multiple OOV words became semantically empty — up to 60% of meaning lost in some cases.

Error 3: Language Filter Edge Cases

Very short comments (<2 words) and code-switched Azerbaijani-Turkish text occasionally evade the filter. Impact: minimal (<2% of filtered data).

🎓 Key Learning Outcomes

📐 Embedding Quality Matters

Frozen embeddings from large combined corpus outperformed fine-tuned models—linguistic pretraining is more valuable than task-specific adaptation with limited data.

🔤 Morphology-Aware Embeddings

FastText's subword approach is essential for morphologically rich, agglutinative languages like Azerbaijani where word forms multiply rapidly.

🛡️ Language-Specific Filtering

Two-layer character + lexicon-based filtering effectively removes Turkish/English noise with 85.7% elimination rate.

📊 Domain-Specific Sentiment

Different domains show distinct sentiment distributions—technology/retail more positive; social life/entertainment more critical and negative.

🔮 Future Improvements

1. Ensemble Methods

Combine Word2Vec + FastText + GloVe embeddings with voting classifier for more robust predictions.

2. Transfer Learning

Fine-tune on unlabeled YouTube data first, then on labeled data. Reduce catastrophic forgetting through staged training.

3. Transformer Models

Experiment with BERT/mBERT for Azerbaijani. Attention mechanisms for better context understanding.

4. Multilingual Models

Multilingual FastText trained on multiple Turkic languages. Better handle Turkish code-switching in YouTube comments.

5. Domain Adaptation

Domain-specific fine-tuning for each of 5 semantic categories to improve within-domain precision.

6. Active Learning

Identify uncertain predictions, collect human annotations for hard cases, and incrementally improve the model.
